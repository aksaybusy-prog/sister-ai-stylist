# ATELIER — AI Гардероб и Персональный Стилист (PWA)

Мобильное веб-приложение (Mobile-First PWA) в эстетике Vogue / Pinterest для оцифровки гардероба, подбора образов по погоде, рекомендаций причёсок и виртуальной примерки с помощью Gemini AI.

## Возможности
- **Пакетная авто-оцифровка гардероба**: загрузка одного или сразу нескольких фото → Gemini Vision автоматически определяет название, категорию, цвет, сезон и стиль и раскладывает вещи по полкам.
- **Локальное хранение**: все фото вещей, сохранённые образы и селфи сжимаются на устройстве и хранятся в `IndexedDB` / `localStorage` без сервера.
- **Живая погода (Open-Meteo)**: по умолчанию Ташкент, с автоматическими подсказками по одежде.
- **Примерочная и подбор причёски**: учёт повода, пожеланий, статуса «в стирке сегодня», погоды и профиля волос → готовый комплект из реальных вещей + 3-шаговая инструкция по причёске.
- **Виртуальная примерочная AI**: генерация реалистичного фото девушки в выбранном образе и с новой причёской (`gemini-nano-banana-2.1`).
- **Аналитика шкафа**: кнопка «Чего не хватает» подбирает 3 базовые вещи для новых сочетаний.
- **PWA**: поддержка установки на экран «Домой» на iPhone и Android.

## Запуск локально
```bash
npm install
npm run dev
```
